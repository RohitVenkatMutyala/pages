sys 01: complete network foundation

1. Local DNS (The Fast Path)

Check the Cache first.

  • Your ISP's Local Resolver holds recent IP addresses in memory.
  • A Cache Hit skips the global internet, keeping latency extremely low.

2. Global DNS (The Slow Path)

Traversing the inverted tree.

  • If the IP isn't cached, the Resolver must interrogate the Root, then the TLD, and finally the Authoritative server to find the target IP.

3. TCP & HTTP (The Payload)

Establishing trust before data transfers.

  • Once the IP is found, the Client executes a TCP 3-Way Handshake (SYN, SYN-ACK, ACK) with the Web Server.
  • Only then is the HTTP GET request sent to fetch the site.
